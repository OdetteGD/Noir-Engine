# Noir.Editor

C# editor-side tooling for Noir 3D Game Engine.

- Project C# scripts live under scripts/csharp/.
- Uses the shared Noir.Mobile.Scripting API (using Noir;).
- Roslyn compilation remains in Noir.CSharp.Compiler.
- This package is editor tooling/SDK code; it is not the managed runtime embedded in the Android APK.
