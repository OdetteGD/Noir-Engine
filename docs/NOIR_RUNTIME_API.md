# Noir 3D Engine Runtime API\n\n## Rendering\n\nThe mobile renderer uses OpenGL ES 3.0 through GLSurfaceView.Renderer and supports:\n\n- procedural sky and animated cloud shading\n- directional sun lighting\n- depth shadow map with 3x3 PCF filtering\n- roughness/metallic PBR-style response\n- environment/specular reflection approximation\n- depth/culling\n- requested 4x MSAA EGL configuration with fallback\n- editor orbit camera\n- runtime FPS/mobile look camera\n\n## Runtime camera\n\nNoirRenderer exposes runtimeLook(dx, dy), runtimeMove(forward, strafe, delta), and setMode(Mode.RUNTIME).\n\nNoirSurface maps the right side of the screen to camera look and the left side to mobile movement.\n\n## Script API\n\nThe built-in API is in com.noir.game.engine.scripting:\n\n- NoirScriptAPI.Input\n- NoirScriptAPI.Transform\n- NoirScriptAPI.Character\n- NoirScriptAPI.Camera\n- NoirScriptAPI.Debug\n- NoirScriptAPI.Time\n- NoirScriptComponent\n- NoirScriptRuntime\n\nA target node stores its attached script path in the node's script property.\n\nExample:\n\nentity PlayerController {\n  type: Character3D\n  property speed: 5.0\n  property jump: 4.5\n  input move_x\n  input move_y\n\n  start {\n    camera = child("Camera3D")\n  }\n\n  physics(delta) {\n    movement = vector(move_x, 0, move_y)\n    velocity = move_and_slide(velocity)\n  }\n}\n\n## Editor runtime boundary\n\nPressing PLAY switches the renderer to runtime mode and hides the editor HUD. The Android back action returns to the editor.\n\n## Mobile performance\n\nThe renderer avoids per-frame mesh allocation, caches GPU buffers, limits shadow resolution to a mobile-friendly default, and uses a forward pipeline instead of a desktop deferred renderer.\n\nThe project intentionally does not inflate the APK with meaningless padding. Size growth should come from real engine code, native runtime libraries, shaders, asset importers, and project assets.
